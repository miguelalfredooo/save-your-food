# Cook log

One line per recipe suggestion and what happened to it. Append-only.
Ranking uses this: recipes that get cooked rank higher, recipes suggested and
ignored rank lower. Sixty recipes on file is not sixty recipes in rotation.

Format: `<Ddd Mon D> | <recipe> | suggested | cooked | ignored | declined: <reason>`

Do not edit history. Add lines; never rewrite them.
